# Metta World Peace Talent Tree

An unofficial English interactive talent guide.

## Preview locally

Open `index.html` directly, or run a local static server from this folder:

```bash
python3 -m http.server 8000
```

Then open `http://localhost:8000`.

## Publish with GitHub Pages

1. Create a public GitHub repository.
2. Upload every file and the `assets` folder from this project.
3. Open **Settings → Pages**.
4. Under **Build and deployment**, choose **Deploy from a branch**.
5. Select the `main` branch and `/ (root)`, then save.

GitHub will provide a public URL after the deployment finishes.

## Notes

- The page contains 27 practical talents across seven branches.
- The unused hidden flourish talent in **Born to Compete** is intentionally omitted.
- Talent details show the max-level information available in the supplied screenshots.
